# Changelog - v2.1.0 (Stability & Hardening Release)

## Summary of Changes

This release focuses strictly on stability, database safety, multi-engine fidelity, and real-world Laravel 13 compatibility.

### 🛡️ Critical Safety & Isolation Fixes
- **Dynamic Connection Cloaking with Locked Driver**: `ShadowMigrationRunner` dynamically cloaks all non-shadow configured connections using a locked custom database driver (`DB::extend()`). Any attempt by migrations, external models, or dynamic application helpers to query a non-shadow connection during simulation triggers an immediate safety abort before any query reaches a live database.
- **Clean Lifecycle Without Reflection**: Replaced internal connection reflection hacks with framework-native configuration restoration and public `DB::purge()` / `DB::disconnect()` cleanup.
- **AST Token Scanner for Explicit Connections**: Replaced fragile regular expressions with `token_get_all()` AST inspection, detecting explicit connection calls (`DB::connection(...)`, `Schema::connection(...)`) and class `$connection` properties.
- **URL & Socket-Aware Collision Interlocks**: Expanded collision checks to parse database connection URLs (`mysql://`, `postgres://`), Unix sockets, localhost aliases (`127.0.0.1`, `localhost`, `::1`, `0.0.0.0`), and symlinks.
- **Clean Exception Handling in PreMigrationGuard**: Replaced `exit(1)` inside `MigrationsStarted` listener with `Sentinel\SchemaSentinel\Exceptions\MigrationBlockedException` and added nested bypass state tracking.
- **Data Protection in Reverse Engineering**: Removed live table record dumping in generated seeders. Replaced with safe developer placeholders.

### ⚙️ Engine Correctness & Migration Generator Hardening
- **Safe PHP Generation with `var_export()`**: All table names, column names, index identifiers, foreign key constraints, default values, and comments in generated migrations now use deterministic `var_export()` literal formatting.
- **Bidirectional Rollback Generation**: Generated migrations produce reverse `->change()` instructions reflecting the live database state, ensuring full bidirectional rollback fidelity.
- **Dialect & Type Alignment**: Resolved SQLite quote unwrapping, MariaDB/MySQL unsigned integer foreign key alignment, and nullable timestamp default normalization. Unsupported custom types raise an actionable `RuntimeException` instead of being silently coerced to strings.
- **Multi-Database Introspection Isolation**: Scoped `SchemaParser` to inspect only tables belonging to the active connection database/schema, preventing cross-database table pollution on MySQL/MariaDB and PostgreSQL.

### 🧪 Comprehensive Database Engine Verification
- **SQLite 3.49.1**: 33 automated package tests (86 assertions) passing 100%. Full drift/fix/rollback lifecycle verified on real Laravel 13.37.0.
- **MariaDB 13.0.2 / MySQL**: Verified against local daemon and container matrix. Tested 12-step lifecycle: drift detection, automated repair generation with `unsigned` integer foreign keys and nullable timestamps, PHP syntax linting, migration application (100% sync), and rollback.
- **PostgreSQL 18.6**: Verified against local daemon and container matrix with schema isolation, drift detection, index audit, and migration simulation.
- **GitHub Actions CI Matrix**: Configured independent matrix jobs for SQLite, MySQL, and PostgreSQL across PHP 8.4 and PHP 8.5 with containerized database services (All 6 matrix jobs passing).
