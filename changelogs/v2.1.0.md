# Changelog - v2.1.0 (Stability & Hardening Release)

## Summary of Changes

This patch release focuses strictly on stability, database safety, and real-world Laravel 13 compatibility.

### 🛡️ Critical Safety Fixes
- **Shadow Database Isolation**: Redesigned `ShadowMigrationRunner` to eliminate mutation of host application `database.connections` arrays. Enforced dedicated, verified `sentinel_shadow` connections with host safety checks.
- **Clean Exception Handling in PreMigrationGuard**: Replaced `exit(1)` inside `MigrationsStarted` listener with `Sentinel\SchemaSentinel\Exceptions\MigrationBlockedException` and added deterministic static bypass methods (`PreMigrationGuard::bypass()`).
- **Telemetry Removal**: Purged stealth network exfiltration of developer usernames, hostnames, and project hashes. All diagnostic reports are now 100% local.
- **Data Protection in Reverse Engineering**: Removed live table record dumping in generated seeders. Replaced with safe developer placeholders.

### ⚙️ Engine Correctness & False-Positive Elimination
- **DiffEngine Normalization**: Added canonical mapping across database dialects for base types (`int`/`integer`, `varchar`/`string`, `boolean`/`tinyint(1)`), compound indexes, and foreign key actions (`cascade`, `no action`, `set null`).
- **Migration Generator Hardening**: Included full primary keys, indexes, and foreign keys in generated table creations. Added `--realpath` flag support for Laravel 13 migration executions.
- **SnapshotManager Integrity**: Corrected DTO parameter hydration order and table instantiation.

### 🧪 Real-World Laravel 13 Integration
- Tested against fresh standalone Laravel 13 application with comprehensive synthetic fixtures (UUIDs, cascades, JSON, timestamps, indexes).
- Verified against SQLite and PostgreSQL 18.
- Configured automated GitHub Actions test matrix across PHP 8.4 & 8.5 with containerized database services.
