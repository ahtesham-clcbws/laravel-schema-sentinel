# Package Launch: v1.0.0

Initial package launch of Laravel Schema Sentinel.

## Features

- **Drift Detection Engine**: Computes structural diffs between live databases and migration blueprints.
- **Shadow Migration Simulation**: Isolated, thread-safe runs of migrations inside an in-memory database schema builder.
- **Visual Terminal Reporting**: Outputs health scores and lists missing tables/columns/indexes using Artisan CLI styling.
- **Slack & Discord Notification Webhooks**: Automated warning alerts for continuous integration pipelines when schema drift is detected.
- **Pre-Migration Guard Event Listener**: Halts migrations on production if manual changes are found.
