# Changelog: v2.0.0 (Latest Major Release)

Welcome to the **v2.0.0** release of Laravel Schema Sentinel. This major update introduces advanced programmatic APIs, reverse-engineering capabilities, index naming validation, data consistency checks, PHP 8.4 compatibility, and structural stability fixes.

## New Core Features

- **Index Naming Standardizer & Optimizer (`schema:standardize-indexes`)**:
  - Automatically identifies non-standard, custom-written index names.
  - Detects duplicate or redundant index configurations (e.g., single-column indexes covered by composite index prefixes).
- **Data Consistency Auditing (`schema:data-drift`)**:
  - Compares lookups/tables between multiple environments and outputs visual data mismatches.
- **Legacy Database Reverse-Engineer Bridge (`schema:reverse`)**:
  - Converts existing database schemas into pristine Laravel migrations, Eloquent Models with inferred relations and modern casts, seeders, and PHP 8.4 Backed Enums.
- **Exposed Programmatic Service APIs**:
  - Rich programmatic access on the core `Sentinel` service and `Sentinel` facade (`Sentinel::check()`, `Sentinel::reverse()`, etc.) for building dashboards or custom CI/CD hooks.

## PHP 8.4 & Laravel 13 Compatibility

- **Implicitly Nullable Parameter Types**: Fixed all deprecated parameter type declarations.
- **Strict Types (`declare(strict_types=1);`)**: Enabled strict typing file-wide across the entire package.
- **Modern Artisan Attributes**: Migrated commands to utilize console attributes (`#[Signature]`, `#[Description]`).

## Bug Fixes

- **Drift Command Simulation Hangs**: Resolved infinite loop condition in shadow migration retries.
- **Docs Command Undefined Property**: Corrected `$fk->localColumns` to `$fk->columns` to avoid crashes during Markdown generation.
- **BigInt Migration Generation**: Corrected raw mapping from `bigint` -> `bigint` to Laravel's official `bigInteger` blueprint schema builder method.
- **SQLite Constraint Fallbacks**: Handled SQLite constraint naming inconsistencies by fallback deterministic naming.
