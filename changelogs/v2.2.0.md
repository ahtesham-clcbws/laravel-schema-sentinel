# Changelog - v2.2.0 (Reliability & Precision Release)

## Summary of Changes

This release focuses on schema comparison precision, migration generation reliability, foreign key replacement safety, and test coverage improvements across supported database engines.

### 🎯 Schema Comparison Accuracy
- **Column Property Precision**: Deep comparison for column length, decimal precision, decimal scale, and unsigned attributes.
- **Type Normalization**: Differentiates `tinyint(1)` (boolean semantics) from numeric `tinyint` (`tinyint(2+)` or unbounded). Preserves meaningful differences between `varchar(100)` and `varchar(255)`.
- **Default Value Normalization**: Added support for PostgreSQL casting unwrapping (e.g., `'draft'::character varying`, `false::boolean`), parenthesized default expressions (`('default')`, `(0)`), timestamp functions (`CURRENT_TIMESTAMP`, `now()`, `localtimestamp`), and boolean bit literals (`b'1'`, `b'0'`).
- **Composite Index Integrity**: Preserves exact column ordering when evaluating composite indexes to prevent false positive matches.
- **Foreign Key Differential Analysis**: Differentiates between missing foreign keys and altered foreign keys (`changedForeignKeys`). Compares referential actions (`onDelete`, `onUpdate`), foreign tables, and target columns.

### 🛠️ Migration Generation Reliability
- **Foreign Key Replacement**: Safely drops altered foreign keys before recreating them with new constraints and restores the original constraints during rollback.
- **Subsecond Unique Filenames**: Generates collision-proof migration filenames using microsecond timestamps and increment counters.
- **Precision Preservation**: Preserves length, precision, scale, unsigned modifiers, and default values in generated `Blueprint` calls.
- **Fail-Safe Type Mapping**: Clearly rejects unsupported custom types with explicit runtime exceptions rather than generating invalid migrations.

### 🛡️ Shadow Database & Guard Safety
- **Enhanced Configuration Restoration**: Guarantees original application connection and default connection states are restored across both success and failure lifecycles.
- **Active Transaction Guard**: Aborts shadow simulation if active transactions exist on any host connection, protecting transaction state.
- **Bypass State Fidelity**: Restores previous `PreMigrationGuard` bypass state rather than blindly toggling to false.

### 🧪 Test Coverage
- Unit tests for column length differences, decimal precision/scale, signed vs unsigned, boolean vs tinyint, index column ordering, default expressions, and foreign key action diffs.
- Feature tests for collision-proof migration filename generation, foreign key replacement migrations, and decimal precision migration generation.
