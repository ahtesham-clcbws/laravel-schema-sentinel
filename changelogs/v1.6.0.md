# Changelog: v1.6.0

Notable changes and optimizations in the v1.6.0 release.

## Features & Enhancements

- **Livewire Visual Dashboard**: Displays interactive health states and table structures directly inside user blade layouts (`<livewire:sentinel-database-health />`).
- **Migration Execution Micro-Timing**: Measures and reports migration execution speeds to pinpoint bottlenecks.
- **Improved MySQL/PostgreSQL Compatibility**: Expands default configuration options and connection parameters to support non-SQLite shadow database runs.
- **Squash Advisor**: Provides alerts in projects with over 100 migration files to encourage database schema dumping.
